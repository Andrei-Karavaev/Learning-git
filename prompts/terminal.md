#5–8 формулировок, которыми вы реально пользовались


python -m venv venv  - Эта команда создает изолированное виртуальное окружение Python.

.\venv\Scripts\Activate.ps1  - Активация виртуального окружения в PowerShell . При выполнении этого кода возникла ошибка.
В Windows по умолчанию запрещено выполнение скриптов PowerShell в целях безопасности.

Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser   -  ввод этой команды разрешил выполнение скриптов PowerShell для текущего пользователя.

pip install pandas   -  Эта команда использует менеджер пакетов pip для загрузки и установки библиотеки pandas в текущее Python-окружение.

git init — команда для создания нового Git-репозитория. Она превращает обычную папку в проект, за которым может следить Git
git add . — выбрать все файлы в папке для сохранения.
git commit — создать сохранённую точку

(git commit -m "Initial commit: setup project and gitignore"  - на этом месте он выдал ошибку.
Каждый раз, когда вы делаете коммит (git commit), Git записывает, кто именно внес изменения.
Эти данные будут отображаться в истории проекта (git log). Если их не задать, Git может выдать ошибку при попытке сохранить изменения.

git config --global user.email "andreykaravaev.work@gmail.com"
git config --global user.name "Andrei-Karavaev"     -  Вносим данные об авторе изменений (обо мне)


git branch -M main  

- git branch — команда для управления ветками.
-M — флаг принудительного переименования (он заставляет Git переименовать ветку, даже если ветка с таким именем уже существует).
main — новое имя, которое вы присваиваете текущей ветке

git remote add origin https://github.com/Andrei-Karavaev/csv-project.git   -  Эта команда связывает ваш локальный репозиторий с удаленным репозиторием на GitHub,
присваивая этому адресу имя origin для удобного обращения к нему.

git push -u origin main  - Команда отправляет ветку main в репозиторий origin и запоминает эту связь, чтобы в будущем я мог делать это одной короткой командой git push
