# Learning-git
Облачная LLM работает через интернет и API: она проще в запуске, автоматически обновляется и легко масштабируется, но требует оплаты, зависит от интернета и менее конфиденциальна. Локальная LLM работает на оборудовании пользователя, может быть офлайн, обеспечивает контроль и приватность, но зависит от мощности устройства и требует самостоятельной настройки и обновлений.

API — правила обмена данными между программами: клиент отправляет серверу запрос с параметрами и API-ключом, сервер возвращает ответ, обычно в JSON. API-ключ нельзя разглашать. При работе с чужими данными важно соблюдать NDA — соглашение, определяющее конфиденциальную информацию, условия её передачи, срок защиты и ответственность за нарушение.
